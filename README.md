# Homecare Operations Analysis

## About the Project

I created this project in Excel to look at how a homecare business is performing across staffing, service types, and regions. I used a simulated dataset to find patterns in the data and see where there may be opportunities to improve operations.

## What I Looked At

* Scheduled hours vs. worked hours
* Staff completion rates
* Missed visits
* Service type demand
* Regional performance
* Overall operational performance

## Excel Skills Used

* COUNTIFS
* SUMIFS
* AVERAGEIFS
* LARGE
* SMALL
* RANK.EQ
* SUMPRODUCT
* Data analysis
* Business analysis

## What's Included

The workbook includes:

* **Raw Data** — The dataset used for the analysis
* **Analysis** — Calculations and comparisons of staff, services, and regions
* **Key Findings** — Main patterns found in the data
* **Dashboard** — A visual summary of the results

## A Few Findings

Personal Care had the highest number of scheduled hours, while Transportation had the most missed visits. The West region had the lowest completion rate, and Staff 03 had the highest completion rate among the staff analyzed.

## Tools

**Microsoft Excel**
